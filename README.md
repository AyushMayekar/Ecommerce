# 🛒 Full-Stack Ecommerce Platform

Welcome to the **Ecommerce Platform** project\! This is a modern, full-stack web application designed to provide a seamless shopping experience. The project leverages **React** for a high-performance frontend and **Django Rest Framework** for a robust, scalable backend.

-----

## 🚀 Tech Stack

The application is built using the following technologies:

| Component | Technology |
| :--- | :--- |
| **Frontend** | [React.js](https://react.dev/) (Powered by [Vite](https://vitejs.dev/)) |
| **Backend** | [Django Rest Framework (DRF)](https://www.django-rest-framework.org/) |
| **Database** | [MongoDB](https://www.mongodb.com/) (Managed via MongoDB Atlas) |
| **Authentication** | [JWT (JSON Web Tokens)](https://jwt.io/) |
| **Styling** | CSS3 / Responsive Design |

-----

## ✨ Key Features (Planned & In-Progress)

  * **User Authentication:** Secure Sign-up, Login, and Logout functionality using JWT.
  * **Product Management:** Browse products with detailed descriptions, pricing, and images.
  * **Shopping Cart:** Add, remove, and update quantities of items in real-time.
  * **Responsive UI:** Optimized for desktop, tablet, and mobile devices.
  * **RESTful API:** A clean API architecture for smooth frontend-backend communication.
  * **Database Integration:** Scalable data storage using MongoDB Atlas.

## 🛠️ Installation & Setup

To get a local copy up and running, follow these steps:

### 1\. Clone the Repository

```bash
git clone https://github.com/AyushMayekar/Ecommerce.git
cd Ecommerce
```

### 2\. Backend Setup (Django)

```bash
cd backend
# Create a virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run migrations and start server
python manage.py migrate
python manage.py runserver
```

### 3\. Frontend Setup (React + Vite)

```bash
cd ../frontend
npm install
npm run dev
```
